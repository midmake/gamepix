# MIDAS Jogos

Plataforma mobile-first de jogos HTML5 da Midas Studio.

## Objetivo atual

Preparar uma experiência pública profissional para apresentação como Publisher à GamePix, sem afirmar parceria ou autorização ainda não concedida.

## Estrutura

- `site/` — conteúdo público publicado no GitHub Pages.
- `partner-concept/` — materiais conceituais privados de proposta, fora do artefato de deploy.
- `.github/workflows/pages.yml` — pipeline de publicação do diretório `site/`.

## Deploy

O site público é publicado pelo GitHub Pages via GitHub Actions a partir exclusivamente do diretório `site/`.

## Estado do catálogo

Os jogos e artes exibidos nesta versão são fictícios e demonstrativos. A área de jogo está preparada para futura integração autorizada via embed/API.

## Fontes de referência

A implementação foi estruturada a partir das páginas oficiais da GamePix para Publishers e da documentação pública de integração. Consulte `GAMEPIX-NOTES.md` para o resumo técnico e as decisões adotadas.
