# MIDAS Jogos — Assets e licenças

Atualizado em 18/08/2026.

## Estado atual

Esta versão não usa screenshots, logos, personagens, capas ou promotional artwork de jogos de terceiros.

Todos os elementos visuais do site público foram criados especificamente para este projeto usando:

- CSS;
- gradientes;
- formas vetoriais/geométricas;
- composição tipográfica;
- SVG original do favicon.

Os nomes de jogos demonstrativos também são fictícios.

## Assets externos

Nenhum asset visual externo é necessário para renderizar a versão atual.

## Partner Concept Mockup

O arquivo `partner-concept/index.html` usa apenas arte fictícia original. Ele não contém arte real de Cut the Rope nem de outro jogo existente. Isso foi escolhido para evitar incorporar IP de terceiros antes de autorização.

Se uma versão futura usar promotional artwork real em material privado de proposta, a origem, a finalidade e a autorização/licença correspondente deverão ser registradas aqui antes do uso.
